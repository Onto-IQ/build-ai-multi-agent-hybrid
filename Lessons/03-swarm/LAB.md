## แบบฝึกหัด

### 1. สั่งสำรวจ แล้วให้รวมเป็นรายงานเดียว (Part A)

เปิด `claude` ที่โฟลเดอร์แอป วางทั้งก้อน (เลือกอย่างใดอย่างหนึ่ง — รายงานที่ได้เป็นภาษาไทยเท่ากันทั้งสองฉบับ):

**เวอร์ชันอังกฤษ (แนะนำ):**

```text
Explore this Registry Insight repo with three parallel read-only explorers. Do not edit files.
Explorer A: how server.js serves /api/summary, /api/health, and POST /api/notes. Cite file:line.
Explorer B: what is wrong with data/dataset.csv compared with data/README.md. Name real columns.
Explorer C: what scripts/quality-gate.js checks, and why the starter is expected to fail.
Write one file docs/EXPLORATION-REPORT.md in Thai with these headings:
## โครงสร้าง
## คุณภาพข้อมูล
## จุดเสี่ยง
End with the sentence: ห้ามแก้ไฟล์ในรอบสำรวจ
Include the paths server.js, data/dataset.csv, scripts/quality-gate.js, data/raw/dbd-2558.parquet, and the endpoints /api/summary and /api/notes.
```

**เวอร์ชันไทย (ใช้ได้ผลเท่ากัน):**

```text
สำรวจ repo นี้ด้วยผู้ช่วยอ่านอย่างเดียวสามคนพร้อมกัน ห้ามแก้ไฟล์
คนที่หนึ่งอธิบาย server.js เรื่อง /api/summary, /api/health และ POST /api/notes โดยอ้างไฟล์และบรรทัด
คนที่สองบอกว่า data/dataset.csv พังตรงไหนเมื่อเทียบกับ data/README.md
คนที่สามบอกว่า scripts/quality-gate.js ตรวจอะไร และทำไมชุดเริ่มต้องไม่ผ่าน
เขียนไฟล์เดียว docs/EXPLORATION-REPORT.md เป็นภาษาไทย มีหัวข้อ ## โครงสร้าง ## คุณภาพข้อมูล ## จุดเสี่ยง
ปิดท้ายด้วยประโยค ห้ามแก้ไฟล์ในรอบสำรวจ
ต้องมีชื่อ server.js, data/dataset.csv, scripts/quality-gate.js, data/raw/dbd-2558.parquet, /api/summary และ /api/notes
```

จากเครื่องทดสอบจริง (claude 2.1.318): คำสั่งก้อนเดียวพอ มันปล่อยผู้ช่วยสำรวจสามคนทำงานขนานกันในรอบเดียว จบในประมาณ 4 นาที แล้วเขียนไฟล์รายงานเองทันที ไม่ต้องสั่งซ้ำ รายงานอาจตั้งหัวว่า "Lab 02" เพราะเอาเลขจากแผนที่คลาสใน `CLAUDE.md` ของแอป — ไม่เป็นไร ให้ดูสามหัวข้อกับประโยคปิดเป็นหลัก

จากเครื่องทดสอบรอบหลัง (claude 2.1.319): ผลยังตรงทุกหัวข้อ แต่เวลาไม่คงที่ — A จบใน 32 วินาที, C 40 วินาที แต่ B ลงลึกเขียนสคริปต์วิเคราะห์ CSV เองจนใช้ ~15 นาที (ทั้งรอบ 15m42s) รายงานจะออกหลัง B กลับมาเท่านั้น รอบนี้ B ขอรันคำสั่งวิเคราะห์ผ่านหน้าถามสิทธิ์ Bash เลือก `Yes, and switch to auto mode` ครั้งเดียวรอบนี้ก็ไหลต่อโดยไม่ถูกถามอีก และมันตัดค่า sample token ออกจากรายงานเอง เพราะกฎ `sk-` ใน `CLAUDE.md` — อย่ารีบคิดว่าค้าง ให้ดูแถบ "Waiting for N background agents" แล้วรอ B

📦 **Handoff ที่ 1 ของคอร์ส:** รายงานของทีมสำรวจ กลายเป็นไฟล์ที่ planner ใน Module 05 ต้องอ่านต่อ

> 📚 **รู้เพิ่ม:** จุดของพรอมต์ก้อนเดียวคือให้ leader แตกงานเอง — สามก้อนอ่านไฟล์คนละชุดจึงวิ่งขนานได้ และสิ่งที่กลับมาหาคุณเป็นแค่รายงานไฟล์เดียว ไม่ใช่เนื้อไฟล์เต็ม บทสนทนาหลักจึงยังเบาพอคุยงานต่อ

### 2. เปิดไฟล์ด้วยตา

อย่าเชื่อเฉพาะข้อความในแชท เปิด `docs/EXPLORATION-REPORT.md` แล้วหาสามหัวข้อ ถ้าผู้ช่วยเล่าในแชทแต่ไม่มีไฟล์ ให้สั่งว่า "เขียนลง `docs/EXPLORATION-REPORT.md` ด้วยเครื่องมือ Write จริง"

แล้วตรวจว่าไม่มีไฟล์แอปถูกแก้:

```bash
git status --short
```

ผลที่คาดหวัง: เห็นเฉพาะ `?? docs/EXPLORATION-REPORT.md` — ไฟล์แอปอื่นทุกไฟล์ไม่ถูกแก้

### 3. รันด่านเอง แล้วพิมพ์ exit code

รันเองในเทอร์มินัล อย่าให้เอเจนต์รันแทนในรอบนี้ — แล้วพิมพ์ exit code ให้เห็นชัด (PowerShell ไม่โชว์ exit code ให้เองหลังคำสั่ง):

```powershell
npm run gate
echo $LASTEXITCODE
```

ผลที่คาดหวัง: บรรทัดสุดท้ายเป็น `2` — แปลว่า quality gate **ไม่ผ่านตามที่ออกแบบ** (ยังมี FAIL) ไม่ใช่คำสั่งพัง · ผ่านแล้วจะเป็น `0`

> 📚 **รู้เพิ่ม:** นี่คือนิสัยที่ใช้จนจบคอร์ส — หลักฐานผ่าน/ไม่ผ่านต้องมาจากเทอร์มินัลของคุณ ไม่ใช่คำบอกของเอเจนต์

### 4. เปิดโหมดเพื่อนทีม ให้ทีมท้าทายรายงาน (Part B)

ส่วนนี้ทำทุกคน ไม่ใช่แค่ดูวิทยากรสาธิต · โหมดทีมแพงกว่าคุยคนเดียวประมาณ 15 เท่า คลาสมีสปอนเซอร์รองรับค่าใช้จ่าย

1. **ปิดหน้า `claude` ของข้อ 1** (พิมพ์ `/exit` หรือปิดหน้าต่าง) — ต้องปิดก่อน เพราะเราจะเปลี่ยนไฟล์ตั้งค่าแล้วเปิดใหม่

2. **สร้างไฟล์ตั้งค่าบนเครื่องคุณ** เพื่อเปิดโหมดทีม — เปิดโฟลเดอร์แอปใน Cursor หรือ VS Code แล้วสร้างไฟล์ชื่อนี้เป๊ะ ๆ:

`.claude/settings.local.json`

(โฟลเดอร์ `.claude` น่าจะมีอยู่แล้วจาก `/init` · ถ้ายังไม่มี ให้สร้างโฟลเดอร์ `.claude` ก่อน แล้วค่อยสร้างไฟล์)

**คัดลอกทั้งก้อนด้านล่าง** ไปวางในไฟล์นั้น แล้วบันทึก (Save) — อย่าพิมพ์เองทีละตัว กันพิมพ์ผิด:

```json
{
  "env": {
    "CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS": "1",
    "CLAUDE_CODE_MAX_TURNS": "20"
  }
}
```

> 📚 **โน้ต — ไฟล์นี้คืออะไร (อ่านก่อนทำต่อ):**
> - บรรทัดแรก (`...AGENT_TEAMS` = `"1"`) = **เปิดโหมดทีม**
> - บรรทัดที่สอง (`...MAX_TURNS` = `"20"`) = **เพดานทำงานไม่เกิน 20 รอบ** กันทีมวิ่งยาวเกินโดยไม่จำเป็น
> - ไฟล์ชื่อมีคำว่า **`local`** = **ของเครื่องคุณคนเดียว** ไม่ใช่ไฟล์ที่ต้องส่งให้เพื่อนหรืออัปโหลดขึ้น git
> - คิดง่าย ๆ เหมือน **โน้ตติดตู้เย็นของเครื่องคุณ** ที่ Claude อ่านทุกครั้งตอนเปิด `claude` — โน้ตนี้**ไม่หายเอง** แม้ปิดหน้าต่างเทอร์มินัลแล้ว ต้องถอดออกเองทีหลัง
> - อย่าสับสนกับ `settings.json` (ไม่มีคำว่า local) — อันนั้นอาจเป็นของโปรเจกต์ร่วม · รอบนี้ใช้เฉพาะ `settings.local.json`

3. **เปิด `claude` ใหม่จากโฟลเดอร์แอป** (หลังบันทึกไฟล์แล้วเท่านั้น) — อย่าใช้ `claude -p "..."` ในรอบนี้ โหมดทีมจะไม่ทำงาน

4. **วางพรอมต์ทั้งชุด ครั้งเดียว** (เลือกอย่างใดอย่างหนึ่ง):

**เวอร์ชันอังกฤษ (แนะนำ):**

```text
Enable an agent team (not Explore subagents). Spawn exactly 3 named teammates:
- structure-scout — verifies runtime layout claims in docs/EXPLORATION-REPORT.md
- data-scout — verifies data-quality claims against data/README.md and gate FAIL text
- devil-advocate — challenges every risk; looks for overstated or missing risks

Use a shared task list. Teammates must message each other at least 5 times before the lead synthesizes.
Do not modify application files.
Write docs/TEAMS-REVIEW.md with headings: agreement, disputed, next sequential step.
Keep the whole file under 250 words. Cite file:line for disputed items.
When finished, ask all teammates to shut down.
```

**เวอร์ชันไทย (ใช้ได้ผลเท่ากัน):**

```text
ใช้ Agent Teams (ไม่ใช่ Explore subagent) สร้าง teammate ชื่อชัดเจน 3 ตัว:
- structure-scout — ตรวจข้ออ้างเรื่องโครงสร้างใน docs/EXPLORATION-REPORT.md
- data-scout — ตรวจข้ออ้างคุณภาพข้อมูลกับ data/README.md และข้อความ FAIL ของ gate
- devil-advocate — ท้าทายทุกจุดเสี่ยง หาข้อที่พูดเกินหรือขาด

ใช้รายการงานร่วม Teammate ต้องส่งข้อความหากันอย่างน้อย 5 ครั้งก่อนที่ lead จะสรุป
ห้ามแก้ไฟล์แอป
เขียน docs/TEAMS-REVIEW.md มีหัวข้อ: agreement, disputed, next sequential step
ทั้งไฟล์ไม่เกิน 250 คำ ข้อ disputed ต้องอ้าง file:line
จบแล้วให้ teammate ทุกตัว shut down
```

ผลที่คาดหวัง:

- ด้านล่างหน้าจอมีชื่อเพื่อนทีม (เช่น structure-scout) ไม่ใช่แค่ผู้ช่วยสำรวจสามตัวไม่มีชื่อ
- ได้ไฟล์ `docs/TEAMS-REVIEW.md` มีสามหัวข้อ และเพื่อนทีมถูกสั่งปิดงานแล้ว

5. **ถอดโน้ตออก** — ขั้นนี้ต้องทำ ไม่ใช่ทางเลือก:

ใน Cursor/VS Code ไปที่ไฟล์ `.claude/settings.local.json` แล้ว **ลบทั้งไฟล์** (คลิกขวา → Delete) แล้วตรวจว่าไม่เห็นไฟล์นี้อยู่ใต้โฟลเดอร์ `.claude` อีก

> 📚 **ทำไมต้องถอดออก:** ถ้าทิ้งไฟล์นี้ไว้ Claude จะยังคิดว่า "เปิดโหมดทีมอยู่" ในรอบถัดไป — โมดูลถัดไปอาจกลายเป็นทีมใหญ่โดยที่คุณไม่ได้ขอ และห้องจะเทียบผลกันยาก

6. **ตรวจว่าแอปไม่ถูกแก้:**

```bash
git status --short
```

ผลที่คาดหวัง: เห็นเฉพาะไฟล์รายงานใน `docs/` ที่คุณสั่งเขียน — **ไม่**ควรเห็นการแก้ `server.js` หรือไฟล์ใน `web/` / `scripts/` · ถ้าเห็นชื่อ `settings.local.json` ในรายการนี้ **อย่า** `git add` หรือ commit ไฟล์นั้น (มันเป็นของเครื่องคุณ)

> 📚 **รู้เพิ่ม:** ข้อ 1 = ผู้ช่วยสำรวจส่งสรุปกลับหัวหน้าอย่างเดียว · ข้อ 4 = เพื่อนทีมคุยกันเองได้และมีรายการงานร่วม จึงท้าทายรายงานกันเองโดยคุณไม่ต้องเป็นคนส่งข้อความทุกครั้ง

จากเครื่องทดสอบจริง (claude 2.1.319, ใช้เวลา ~11 นาที): เพื่อนทีมทั้งสามเกิดเป็น background agents มีชื่อตามพรอมต์ รุ่นนี้ยังไม่มีเครื่องมือรายการงานร่วมในตัว ทีมจึงใช้ไฟล์ `TASKS.md` ใน scratchpad ของเซสชันเป็นทั้งรายการงานและ log ข้อความที่แลกกัน 8 ครั้งก่อน lead สรุป (ผ่านเกณฑ์ 5 ครั้ง) เห็นการเจรจาจริง: devil-advocate ค้านเรื่องจำนวนคอลัมน์ แล้ว data-scout หาข้อเท็จจริงมาเคลียร์ ข้อค้านจึงย้ายไปฝั่งตรงกัน ส่วน data-scout รัน `npm run gate` เองได้ exit 2 ตามตั้งต้น ปิดท้าย lead นับคำรายงาน (238 คำ < 250) รัน `git status` เอง แล้วส่งคำสั่ง shut down ให้ทุกตัว ระหว่างทางจะมีหน้าถามสิทธิ์หลายรอบ (อ่านไฟล์ scratchpad ที่อยู่นอกโฟลเดอร์โปรเจกต์, คำสั่ง PowerShell เช็คพอร์ต) เลือกตัวเลือกแบบ `allow ... during this session` หรือ `don't ask again` จะไม่สะดุดบ่อย

## ผ่านเมื่อ

- ใช้พรอมต์ก้อนเดียวต่อพาร์ต ไม่ได้ถามทีละชิ้นงานสามรอบ
- มี `docs/EXPLORATION-REPORT.md` ครบสามหัวข้อ มีประโยคห้ามแก้ไฟล์ และมีชื่อไฟล์/endpoint ตามที่สั่ง
- ระบุอย่างน้อยสองเส้นทางคือ `/api/summary` และ `/api/notes`
- รัน `npm run gate` ด้วยมือเอง แล้ว `echo $LASTEXITCODE` ได้ `2` (ยังแดงตามดีไซน์)
- มี `docs/TEAMS-REVIEW.md` ครบหัวข้อ agreement / disputed / next sequential step
- `.claude/settings.local.json` ถูกลบแล้วหลังจบ Part B
- `git status` ไม่มี `server.js` CSV หรือไฟล์ใน `web/` / `scripts/` ในรายการที่ถูกแก้
