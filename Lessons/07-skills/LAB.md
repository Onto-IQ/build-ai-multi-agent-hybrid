## แบบฝึกหัด

### 1. เช็กลิสต์ปล่อยของบน Claude

เปิด `claude` วาง:

```text
สร้าง .claude/skills/release-checklist/SKILL.md
description ภาษาอังกฤษ: Use before releasing the Registry Insight app
เนื้อหาให้ตรวจสี่อย่างตามลำดับ: เซิร์ฟเวอร์เปิดได้, /api/health ไม่มี sk- โดยห้ามพิมพ์ค่า, ปิดเซิร์ฟเวอร์ก่อนรันด่าน, รัน npm run gate แล้วบันทึก exit code จริง
จากนั้นสร้าง .claude/agents/release-manager.md ที่ใช้ skill นี้ และมี Bash ใน tools แต่ห้ามพิมพ์ค่า sk-
```

ปิดแล้วเปิด `claude` ใหม่ แล้ววาง:

```text
ใช้ release checklist ตรวจแอปนี้ รายงาน PASS หรือ FAIL ทีละข้อ พร้อมหลักฐานสั้น ๆ ถ้ารัน gate ให้บอก exit code จริง
```

### 2. ความจำบน OpenCode

เปิด `opencode` วาง:

```text
เขียน docs/MEMORY.md เป็นภาษาไทย จำห้าข้อนี้
แอปคือ Registry Insight จากข้อมูลจดทะเบียนใหม่ พ.ศ. 2558
ด่านต้องเป็น 6/6 ก่อนบอกว่าเสร็จ
ห้ามแก้ scripts/quality-gate.js
ห้ามพิมพ์ค่าที่ขึ้นต้นด้วย sk-
โน้ตบนเครื่องเขียนไฟล์ได้ โน้ตบน Vercel เป็นอ่านอย่างเดียว
ห้ามใส่คีย์ลงไฟล์นี้
```

ปิด OpenCode ให้สนิท เปิดใหม่ แล้วถามโดยไม่แปะห้าข้อนั้นซ้ำ:

```text
อ่าน docs/MEMORY.md แล้วบอกฉันว่าก่อนส่งของต้องเห็นด่านแบบไหน และโน้ตบน Vercel ทำไมเขียนไฟล์ไม่ได้
```

คำตอบต้องมาจากไฟล์ ไม่ใช่จากการเดาทับ

## ผ่านเมื่อ

- มี skill `release-checklist` และมีรายงาน PASS/FAIL ที่พูดถึง exit code ของด่าน
- เปิด OpenCode รอบใหม่แล้วยังตอบเรื่อง 6/6 และโน้ตอ่านอย่างเดียวได้จาก `docs/MEMORY.md`

## ถ้าตามไม่ทัน

```bash
node scripts/catch-up.js w5
```

ได้เช็กลิสต์และไฟล์ความจำอ้างอิง ให้อ่านแล้วเรียกใช้เองหนึ่งรอบ
