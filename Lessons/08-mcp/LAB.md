# Module 08 — สาธิต MCP วิทยากรเท่านั้น

**ทำไปเพื่ออะไร:** ให้เห็นว่าผู้ช่วยถามข้อมูลใน DuckDB ได้โดยไม่ต้องให้ผู้เรียนลงเครื่องมือเพิ่มทั้งห้อง

| เวลา | ใครทำ |
|---|---|
| **15 นาที** ในวันที่ 2 | วิทยากรสาธิต ผู้เรียนดู |

ไม่ใช่แบบฝึกหัดส่งของ ไม่มีเกณฑ์ผ่านของผู้เรียน

## สิ่งที่แสดง

1. เปิด [reference/mcp.json.example](../../reference/mcp.json.example) ใน repo บทเรียน ชี้ว่าเป็น DuckDB แบบอ่านอย่างเดียว ไม่มี `--read-write` และไม่มีคีย์
2. ที่เครื่องวิทยากร ซึ่งลง `uv` ไว้แล้ว ก็อปไฟล์นั้นเป็น `.mcp.json` ในโฟลเดอร์แอป แล้วเปิด Claude
3. ถามเป็นภาษาคนว่า ภาคไหนทุนจดทะเบียนสูงสุดในปี 2558 ให้ตอบจาก SQL ไม่ใช่จากความจำ
4. ปิดด้วยประโยคเดียว: MCP คือปลั๊กให้อ่านของที่มีอยู่ ห้องนี้ไม่ให้ผู้เรียนตั้งเอง เพราะกินเวลาและพังง่ายบน Wi-Fi องค์กร

ชุดอ้างอิงอยู่ที่ `solutions/w6/` ใช้ `node scripts/catch-up.js w6` บนเครื่องวิทยากรได้ อย่าสั่งทั้งห้องให้ตามคำสั่งนี้

## ไม่ทำในห้อง

- ไม่ให้ผู้เรียนสมัครเซิร์ฟเวอร์ MCP
- ไม่เทียบ MCP กับ CLI เป็นแล็บส่ง
- ไม่ใส่คีย์ลง `.mcp.json`
