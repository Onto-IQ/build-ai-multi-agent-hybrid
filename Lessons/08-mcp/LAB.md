# Module 08 — สาธิต MCP วิทยากรเท่านั้น

**ทำไปเพื่ออะไร:** ให้เห็นว่าผู้ช่วยถามข้อมูลใน DuckDB ได้โดยไม่ต้องให้ผู้เรียนลงเครื่องมือเพิ่มทั้งห้อง

| เวลา | ใครทำ |
|---|---|
| **15 นาที** ในวันที่ 2 | วิทยากรสาธิต ผู้เรียนดู |

ไม่ใช่แบบฝึกหัดส่งของ ไม่มีเกณฑ์ผ่านของผู้เรียน

## สคริปต์สาธิต

1. เปิด [reference/mcp.json.example](../../reference/mcp.json.example) ใน repo บทเรียน ชี้ให้ห้องดูสามจุด: เป็น DuckDB แบบอ่านอย่างเดียว (**ไม่มี** `--read-write`), pin `--python 3.12` ห้ามตัด (Python ใหม่กว่าทำ `cryptography` build ล้ม), และไม่มีคีย์ใด ๆ
2. ที่เครื่องวิทยากร ซึ่งลง `uv` ไว้แล้ว ก็อปไฟล์นั้นเป็น `.mcp.json` ในโฟลเดอร์แอป แล้วเปิด Claude — กล่องแรกจะถามอนุมัติเซิร์ฟเวอร์ `data-duckdb` เลือกอนุญาตสำหรับโปรเจกต์นี้
3. ถามเป็นภาษาคน: "ภาคไหนทุนจดทะเบียนสูงสุดในปี 2558" — ชี้ให้ห้องดูว่ามันรัน SQL ผ่าน MCP เอง ไม่ได้ตอบจากความจำ และขอบเขตอ่านอย่างเดียวจึงแก้ข้อมูลไม่ได้แม้จะลอง
4. ถามซ้ำด้วย query สรุปรายเดือน (ใช้ `TRY_CAST` ไม่ใช่ `CAST` เพราะมีแถวหัวตารางปน — `CAST` ล้มทั้ง query ทันทีที่เจอค่าแปลงไม่ได้) ยอดอ้างอิงจากข้อมูลจริง: ม.ค. 18,620,752,814 · ก.พ. 14,815,712,210 · มิ.ย. 11,905,403,760 บาท
5. ปิดด้วยประโยคเดียว: **MCP คือปลั๊กให้อ่านของที่มีอยู่ ห้องนี้ไม่ให้ผู้เรียนตั้งเอง** เพราะกินเวลาและพังง่ายบน Wi-Fi องค์กร — อ่านบทเรียนเต็มได้จากต้นฉบับถ้าสนใจลงเองภายหลัง

ชุดอ้างอิงอยู่ที่ `solutions/w6/` ใช้ `node scripts/catch-up.js w6` บนเครื่องวิทยากรได้ อย่าสั่งทั้งห้องให้ตามคำสั่งนี้

## ถ้าสาธิตแล้วติดขัด (สำหรับวิทยากร)

| อาการ | สาเหตุ | แก้ |
|---|---|---|
| เปิด Claude ไม่ขึ้นถามอนุมัติ MCP | `.mcp.json` ไม่อยู่รากโฟลเดอร์แอป หรือเปิดผิดโฟลเดอร์ | ตรวจ `Get-Content .mcp.json` แล้วปิดเปิด Claude ใหม่ |
| uvx โหลดแพ็กเกจนานหรือ build ล้ม | เครือข่ายองค์กรหรือ Python ไม่ใช่ 3.12 | ทดลองบน Wi-Fi สำรองก่อนคลาส · คง `--python 3.12` ไว้ |
| ตอบยอดจากความจำแทน SQL | คำถามกว้างเกิน | ใช้คำถามที่ระบุ "จากข้อมูลใน DuckDB" แล้วขอตารางรายเดือน |

## ไม่ทำในห้อง

- ไม่ให้ผู้เรียนสมัครเซิร์ฟเวอร์ MCP
- ไม่เทียบ MCP กับ CLI เป็นแล็บส่ง
- ไม่ใส่คีย์ลง `.mcp.json`
