# Module 08 — สาธิต MCP (วิทยากรเท่านั้น)

## Key idea / แนวคิดหลัก — เล่าเป็นเรื่อง

MCP (Model Context Protocol) คือปลั๊กมาตรฐานให้ผู้ช่วยต่อไปยังของที่มีอยู่แล้ว — ฐานข้อมูล เอกสาร เครื่องมือในบริษัท — โดยผู้ช่วยถามเป็นภาษาคนแล้วมันแปลงเป็นคำสั่งที่ถูกชนิดเอง ที่ห้องนี้**สาธิตแต่ไม่ให้ผู้เรียนตั้งเอง** เพราะการติดตั้งกินเวลาและพังง่ายบน Wi-Fi องค์กร 15 นาทีของส่วนนี้ซื้อ "ความเข้าใจว่ามีปลั๊กแบบนี้" ไม่ใช่ทักษะติดตั้ง

ตัวอย่างที่เลือกดีใจคือ DuckDB แบบ**อ่านอย่างเดียว**: ไฟล์ `reference/mcp.json.example` ไม่มี `--read-write` และไม่มีคีย์ใด ๆ ผู้ช่วยจึงถามข้อมูลได้แต่แก้ไม่ได้ — ปรัชญาสิทธิ์เดียวกับ `data-researcher` ใน Module 04 แต่ครอบคลุมถึงฐานข้อมูล

## Concept / เนื้อหา

### Part A — สคริปต์สาธิต (ผู้สาธิต: วิทยากร)

1. เปิด [reference/mcp.json.example](../../reference/mcp.json.example) ชี้สามจุด: อ่านอย่างเดียว (ไม่มี `--read-write`), ไม่มีคีย์, ชี้ไฟล์ `data/warehouse.duckdb` ที่มีมากับแอป
2. ที่เครื่องวิทยากร (ลง `uv` ไว้แล้ว) ก็อปเป็น `.mcp.json` ในโฟลเดอร์แอป แล้วเปิด Claude
3. ถามภาษาคน: "ภาคไหนทุนจดทะเบียนสูงสุดในปี 2558" — ต้องเห็นมันเขียน SQL รันผ่าน MCP แล้วตอบจากผลจริง ไม่ใช่ตอบจากความจำโมเดล
4. ปิดด้วยประโยคเดียว: MCP คือปลั๊กให้อ่านของที่มีอยู่ ห้องนี้ไม่ให้ผู้เรียนตั้งเอง

### Part B — ผู้เรียนต้องเหลืออะไรหลังจบส่วนนี้

- เข้าใจว่า `.mcp.json` คือตัวต่อระหว่างผู้ช่วยกับแหล่งข้อมูล และไฟล์นี้ห้ามมีคีย์
- เห็นความต่างระหว่าง "ตอบจาก SQL จริง" กับ "ตอบจากความจำ" — เทียบได้กับรายงาน Module 03 ที่อ้างไฟล์จริง
- รู้ว่าแอปของตัวเอง**ยังไม่มี `.mcp.json`** (ผู้เรียนไม่สร้าง) — ถ้ากลับไปดู `git status` ต้องไม่เจอไฟล์นี้

### Part C — ทำไมไม่เทียบ MCP กับ CLI เป็นแล็บ

คอร์สตัดหัวข้อนี้ออกตั้งแต่แผนตั้งต้น (ดู README ราก หัว "ตัดออกจากห้องนี้") เพราะคุณค่าของห้องอยู่ที่สายการผลิตและวินัยส่งมอบ ไม่ใช่การเทียบเครื่องมือ ใครอยากลองเองหลังคอร์ส ชุดอ้างอิงอยู่ที่ `solutions/w6/`

## ลำดับในห้อง (ภาพรวม)

## Quick check / ทบทวน

- ทำไม MCP ตัวอย่างต้องอ่านอย่างเดียว? — เพื่อให้ผู้ช่วยถามข้อมูลได้โดยไม่มีทางแก้ต้นทาง ลดความเสี่ยงมากที่สุดในรูปแบบที่ง่ายที่สุด
- ผู้เรียนต้องตั้ง `.mcp.json` ไหม? — ไม่ ห้องนี้ตั้งใจให้เห็นก่อน ใครจะลองทำหลังคอร์สมีชุดอ้างอิงพร้อม
- รู้ได้ยังไงว่าคำตอบมาจากข้อมูลจริง? — ดูว่ามันเขียน SQL และอ่านผลจาก MCP ต่อหน้า ถ้าตอบเปล่า ๆ ไม่มีที่มา ให้ถือว่าเป็นความจำโมเดล
