|---|---|

ถ้าห้องช้า ให้วิทยากรสาธิตส่วนนี้ได้ ส่วนที่ยุบทั้งแล็บได้คือ [Module 11](../11-feature/LAB.md)

ทำในโฟลเดอร์แอป

## ก่อนเริ่ม

มีเช็กลิสต์จาก [Module 07](../07-skills/LAB.md) และด่านยังเป็น 6/6

## แบบฝึกหัด

เปิด `opencode` วาง:

```text
เขียน docs/MEMORY.md เป็นภาษาไทย จำห้าข้อนี้
แอปคือ Registry Insight จากข้อมูลจดทะเบียนใหม่ พ.ศ. 2558
ด่านต้องเป็น 6/6 ก่อนบอกว่าเสร็จ
ห้ามแก้ scripts/quality-gate.js
ห้ามพิมพ์ค่าที่ขึ้นต้นด้วย sk-
โน้ตบนเครื่องเขียนไฟล์ได้ โน้ตบน Vercel เป็นอ่านอย่างเดียว
ห้ามใส่คีย์ลงไฟล์นี้
```

ปิด OpenCode ให้สนิท เปิดใหม่ แล้วถามโดยไม่แปะห้าข้อนั้นซ้ำ:

```text
อ่าน docs/MEMORY.md แล้วบอกฉันว่าก่อนส่งของต้องเห็นด่านแบบไหน และโน้ตบน Vercel ทำไมเขียนไฟล์ไม่ได้
```

คำตอบต้องมาจากไฟล์ ไม่ใช่จากการเดาทับ และตรวจด้วยตาว่าไฟล์ไม่มีค่าที่ขึ้นต้น `sk-` แม้เป็นตัวอย่าง

## ผ่านเมื่อ

- มี `docs/MEMORY.md` ครบห้าข้อ ไม่มีคีย์หรือค่าลงไฟล์
- ปิด OpenCode ให้สนิทแล้วเปิดใหม่จริง (ไม่ใช่แค่สั่งต่อใน session เดิม)
- คำตอบรอบใหม่อ้างข้อตกลงจากไฟล์ได้ครบทั้ง 6/6 และโน้ตอ่านอย่างเดียวบน Vercel

## ถ้าติดขัด

| อาการ | สาเหตุ | แก้ |
|---|---|---|
| รอบใหม่ยังตอบถูกทั้งที่ไม่มีไฟล์ | ปิดไม่สนิท session เดิมยังอยู่ | ปิดหน้าต่างจริง เช็กว่าไม่มี `--continue` แล้วเปิดใหม่ |
| รอบใหม่ไม่จำ | ไม่ได้สั่งให้อ่านไฟล์ก่อนตอบ | คำถามต้องขึ้นต้นว่า "อ่าน docs/MEMORY.md แล้ว…" |
| เขียน MEMORY.md ใส่คีย์ | เข้าใจผิดว่าคือที่เก็บค่า | ลบทันที ไฟล์นี้ถูก commit คนถัดไปอ่าน |

## ต่อยอด

ผูกความจำเข้าบทบาท: เพิ่มบรรทัดใน `.opencode/agents/data-researcher.md` ให้อ่าน `docs/MEMORY.md` ก่อนตอบทุกครั้ง แล้วถาม data-researcher ใน session ใหม่ — เห็นว่าบทบาทกับความจำร่วมทำงานร่วมกันได้

## ถ้าตามไม่ทัน

```bash
รันจาก repo บทเรียน (build-ai-multi-agent-hybrid) ไม่ใช่จากโฟลเดอร์แอป:
node scripts/catch-up.js w5
```

ชุดนี้มีทั้งเช็กลิสต์และ `docs/MEMORY.md` ให้อ่านไฟล์ความจำแล้วถามรอบใหม่เองหนึ่งครั้ง
