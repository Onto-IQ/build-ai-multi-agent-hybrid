# ชุดตามให้ทัน

รันจาก repo บทเรียน ไฟล์จะถูกคัดลอกไปที่ repo แอป

```bash
node scripts/catch-up.js w4
```

| คำสั่ง | โมดูล | หมายเหตุ |
|---|---|---|
| `init` | 02 | ได้ `AGENTS.md` ไม่ทับ `CLAUDE.md` ของแอป |
| `w1` | 03 | รายงานสำรวจ |
| `w2` | 04 | ผู้เชี่ยวชาญอ่านอย่างเดียวทั้งสองเครื่องมือ |
| `perm` | 04 เส้นสิทธิ์ (พาร์ตรั้วท้าย LAB.md) | ไม่มีคีย์ ไฟล์ตั้งค่าอ้างอิงสำหรับขั้น 4 ของ `Lessons/04-specialty-agents/LAB.md` |
| `w3` | 05 | แผน SQL และตัวสรุป ยังไม่ปิดบั๊กโน้ต |
| `w4` | 06 | เซิร์ฟเวอร์ที่ผ่านเรื่องโน้ตและ health |
| `w5` | 07 และ 10 | เช็กลิสต์และความจำ |
| `w6` | 08 สาธิต MCP | วิทยากร |
| `w7` | 09 | รั้วกับงบ และวาง CSV สะอาดทับ |
| `w8` | 11 | ไม่มีไฟล์ให้คัดลอก มีแต่เกณฑ์ |
| `w9` | 12 และทางลัดของ 13 | ทีมปิดงาน, โน้ตบน Vercel แบบอ่านอย่างเดียว, CSV สะอาด |

`w7` กับ `w9` อ่านไฟล์สะอาดจาก `solutions/data/dataset.clean.csv` (16,772 แถว) แล้วเขียนทับ `data/dataset.csv` ในแอป

ตรวจชุดอ้างอิงโดยไม่ต้องมีแอป:

```bash
node scripts/check-solutions.mjs
```

ถัดมีแอปและอยากพิสูจน์ว่าชุดปิดงานผ่านด่าน 6/6:

```bash
node scripts/check-solutions.mjs --live
```

ไฟล์อ้างอิงชุดสำรวจ แผน ด่าน และสรุป ปรับมาจากคอร์ส Claude อย่างเดียวของ Onto-IQ (`build-ai-multi-agent-with-claude`) แล้วเติมฝั่ง OpenCode กับโน้ตแบบอ่านอย่างเดียวบน Vercel สำหรับห้องไฮบริดนี้
