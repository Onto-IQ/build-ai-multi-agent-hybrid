# ด่านต้นทุนของคลาส

ใช้กับ Lab 07 เพดานนี้เป็นของห้องเรียน ไม่ใช่บิลจริงของ Anthropic

- งบต่อรอบที่บันทึกในไฟล์ usage ไม่เกิน **2 ดอลลาร์**
- output tokens ไม่เกิน **20,000**
- ถ้าเกิน สคริปต์ `scripts/cost-gate.js` ในชุดอ้างอิงจบด้วย exit 2
- แก้แล้วตรวจซ้ำได้ไม่เกิน **2 รอบ** แล้วยังแดงให้หยุดแล้วเรียกวิทยากร
- ห้ามใส่คีย์โมเดลบน Vercel เพื่อ “แก้” เรื่องงบ ค่าโมเดลเกิดบนเครื่องที่รัน Claude / OpenCode
