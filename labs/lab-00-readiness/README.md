# Lab 00 — เช็กว่าเครื่องพร้อม

**ทำไปเพื่ออะไร:** วันเรียนได้ลงมือทันที ไม่เสียครึ่งวันติดตั้งโปรแกรม

| เวลา | เครื่องมือ | ในห้อง |
|---|---|---|
| ทำการบ้านก่อนวันเรียน ทั้งก้อน · ในห้องใช้ **15 นาที** | Claude Code และ OpenCode | รันสคริปต์แล้วอ่านบรรทัด FAIL |

## ก่อนเริ่ม

ทำ [SETUP.md](../../SETUP.md) จนครบ เปิดเทอร์มินัลที่ repo บทเรียน ไม่ใช่แค่โฟลเดอร์ `labs/`

## แบบฝึกหัด

### 1. รันสคริปต์ตรวจ

Windows:

```powershell
cd C:\dev\build-ai-multi-agent-hybrid
powershell -ExecutionPolicy Bypass -File scripts/readiness-check.ps1
```

Mac:

```bash
cd ~/dev/build-ai-multi-agent-hybrid
bash scripts/readiness-check.sh
```

### 2. อ่านผลทีละบรรทัด

- `OK` ผ่านข้อนั้น
- `WARN` ยังเข้าวันที่ 1 ได้ แต่อ่านให้จบ DuckDB ต้องมีก่อน Lab 05 บัญชี Vercel ต้องมีก่อน Lab 11
- `FAIL` แก้ตามข้อความ แล้วรันใหม่ ยังไม่เข้าแล็บถัดไป

### 3. เปิดแอปครั้งหนึ่ง

ที่โฟลเดอร์ `multi-agent-workshop` รัน `npm start` เปิด http://127.0.0.1:3000 แล้วปิดด้วย Ctrl+C จากนั้น `npm run gate` ต้องจบด้วย exit 2

## ผ่านเมื่อ

- สคริปต์ขึ้น `verify-setup: passed`
- `ANTHROPIC_API_KEY` ว่าง และไม่ได้เอาค่าคีย์ไปวางในแชทหรือใน git
- หน้าเว็บเปิดได้ และด่านเริ่มต้นเป็นสีแดงตามที่ออกแบบไว้

## ถ้าตามไม่ทัน

แล็บนี้ไม่มีชุดเฉลย ถ้าเครื่องใครยังแดง ให้เพื่อนที่ผ่านแล้วนั่งคู่ช่วง 15 นาทีแรก อย่าข้ามไป Lab 01 ทั้งที่ `claude` หรือ `opencode` ยังเปิดไม่ได้

## รู้เพิ่ม

สคริปต์ไม่พิมพ์ค่าคีย์ มันบอกแค่ความยาว ถ้าเห็นตัวคีย์เต็ม ๆ บนจอ แปลว่าไปพิมพ์เอง อย่าส่งภาพนั้น
