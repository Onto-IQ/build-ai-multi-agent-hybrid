# สิ่งที่ควรแก้ใน multi-agent-workshop

รอบนี้ไม่แก้ repo แอป รายการด้านล่างทำให้คลาสไฮบริดและ Lab 11 เดินตรงกับของที่ผู้เรียนโคลน

แอปตอนนี้ยังรันได้เป็นจุดเริ่ม: `npm start`, `npm run gate` แดง 0/6 ตามดีไซน์, ข้อมูลจริงอยู่ครบ ชุดปิดงานใน `solutions/w9` ของ repo บทเรียนวางทับแล้วด่านขึ้น 6/6

## ควรแก้

1. **`package.json` คำอธิบายยังเขียนว่า Sales Insight** ให้เป็น Registry Insight จะได้ไม่สับสนตอนผู้ช่วยอ่านไฟล์
2. **`CLAUDE.md` บังคับให้โน้ตอยู่รอดด้วยการเขียนไฟล์** ถูกสำหรับเครื่องผู้เรียนและสำหรับด่าน `notes-persists` ควรเพิ่มข้อยกเว้นว่าบน Vercel (`process.env.VERCEL`) โน้ตเป็นอ่านอย่างเดียว ห้ามเขียนไฟล์ ไม่งั้นผู้ช่วยจะพยายามเซฟโน้ตบน serverless แล้วสู้กับ Lab 11
3. **`scripts/verify-setup.mjs` ตรวจแค่ Claude** คลาสนี้ต้องมี OpenCode ด้วย ควรเช็กว่า `opencode` อยู่บน PATH, ตัวแปร `OPENROUTER_API_KEY` ไม่ว่างโดยไม่พิมพ์ค่า, และ `ANTHROPIC_API_KEY` ว่าง จนกว่าจะแก้ สคริปต์ใน repo บทเรียนครอบคลุมจุดนี้
4. **`server.js` ฟังที่ `127.0.0.1` และไม่มี `vercel.json`** ตั้งใจให้ผู้เรียนสร้าง `api/` เองใน Lab 11 ไม่ต้องใส่ของ deploy มาในชุดเริ่ม ควรเขียนใน `CLAUDE.md` ว่าทางขึ้นของจริงคือ `api/*.js` ไม่ใช่การเอา `server.js` ไปฟังพอร์ตบน Vercel
5. **ข้อความ error ใน `scripts/quality-gate.js` ยังพูดถึง `sales.csv`** เป็นชื่อเก่า ควรเป็น `dataset.csv` เพื่อไม่ให้ผู้ช่วยไปหาไฟล์ที่ไม่มี
6. **หน้าเว็บชุดเริ่มไม่มีช่องโน้ต** ด่านยิงที่ API อย่างเดียว Lab 11 ให้เพิ่มป้ายโน้ตแบบอ่านอย่างเดียวตอน deploy ถ้าอยากให้ชุดเริ่มสื่อเรื่องนี้ตั้งแต่ต้น ค่อยใส่ประโยคบนหน้าเว็บว่าโน้ตบนของจริงจะไม่เขียนไฟล์

## ไม่ต้องแก้

- อย่าทำให้ด่าน `notes-persists` หลวมลง เครื่องผู้เรียนยังต้องเซฟโน้ตลง `data/notes.json`
- อย่าใส่คีย์โมเดลหรือไฟล์ `.env` ตัวอย่างที่มีค่าจริง
- อย่าใส่ `.mcp.json` มาในชุดวันแรก ผู้เรียนยังไม่ต่อ MCP วิทยากรสาธิตเอง
- `.gitignore` มี `.env` และ `data/notes.json` แล้ว ใช้ต่อได้

## ของที่แล็บสั่งให้ผู้ช่วยสร้างในแอป (ไม่ใช่งานของชุดเริ่ม)

- `AGENTS.md` จาก Lab 01
- รายงาน แผน SQL และผู้ช่วย ตาม Lab 02–10
- `vercel.json`, `api/summary.js`, `api/health.js`, `api/notes.js` ที่ POST ตอบ 405 และไม่มี `writeFile`
- หน้าเว็บที่ดึงโน้ตแบบ GET อย่างเดียวบนของจริง
